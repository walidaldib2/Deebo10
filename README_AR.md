# DEBOO16 — النسخة المحلية المؤقتة

هذه نسخة تعمل دون Supabase أو إنشاء مشروع خارجي. تحتفظ بالبيانات محليًا باستخدام IndexedDB داخل المتصفح.

## التشغيل
1. فك ضغط `DEBOO16_LOCAL.zip`.
2. ارفع جميع الملفات مباشرة إلى جذر مستودع GitHub (لا تضعها داخل مجلد إضافي).
3. فعّل GitHub Pages من Settings > Pages > Deploy from a branch > main > /(root).
4. افتح رابط الموقع الناتج من GitHub Pages. استخدم HTTPS حتى يعمل تثبيت PWA وخدمة العمل دون اتصال بصورة أفضل.
5. يمكنك أيضًا تشغيله على الكمبيوتر من داخل مجلد الملفات عبر:
   `python -m http.server 8000`
   ثم افتح `http://localhost:8000`.

## حفظ البيانات
- تُحفظ السجلات في IndexedDB على نفس الجهاز والمتصفح.
- لا تمسح بيانات الموقع ولا تستخدم وضع التصفح الخفي إذا كنت تريد الاحتفاظ بالسجلات.
- لا تنتقل البيانات تلقائيًا إلى جهاز آخر أو متصفح آخر.
- من الإعدادات أنشئ نسخة JSON احتياطية بشكل دوري وانقلها إلى مكان آمن.
- استعادة النسخة تستبدل بيانات النسخة المحلية الحالية بعد التحقق منها، ويتم تنزيل نسخة من الحالة الحالية قبل الاستعادة.

## الطقس والاتصال
الطقس الحقيقي من Open-Meteo يحتاج اتصال إنترنت. بقية وظائف إدارة السجلات الأساسية تعمل محليًا بعد تحميل التطبيق.

## حدود النسخة المحلية
هذه نسخة مؤقتة لمستخدم واحد وعلى جهاز واحد. لا توفر مزامنة سحابية أو حسابات فريق أو صلاحيات متعددة الأجهزة. المرفقات الثنائية، QR، الخرائط المدمجة، WebAuthn/البصمة، والتوقيع الإلكتروني الموثق ليست مفعلة في هذه النسخة. لا تُستخدم كقاعدة تشغيل متعددة المستخدمين أو كبديل عن نظام خادم مؤمن.

## الملفات
- `index.html`: واجهة DEBOO16.
- `style.css`: التصميم الكحلي والذهبي.
- `app.js`: التنقل والوظائف والطقس والتقارير.
- `db.js`: قاعدة IndexedDB المحلية والنسخ الاحتياطي.
- `manifest.json`, `sw.js`, `icon.svg`: PWA والأيقونة.
- `FEATURES_STATUS_AR.md`: ملخص حدود الميزات.
